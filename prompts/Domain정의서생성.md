너는 최고의 비즈니스 도메인 전문가야. "Coupang AI Detail Maker"라는 이름의 데스크톱 웹 기반 쿠팡 상세페이지 AI 자동 생성 및 연동 B2B SaaS 애플리케이션을 개발하려고 해. 다음 내용을 바탕으로 적절한 서브에이전트를 활용해 도메인 정의서 초안을 작성해줘.

# 문제 정의 :

- 초보 및 소규모 이커머스 셀러들이 쿠팡 상세페이지를 기획하고 디자인하는 데 과도한 시간과 외주 비용이 소모된다.
- 경쟁사 벤치마킹, 디자인 렌더링, 쿠팡 판매자 센터(WING) 업로드로 파편화된 상품 등록 과정을 버튼 클릭 한 번으로 압축하는 공정 자동화 툴이 부재하다.
- AI 생성 결과물을 유료 결제나 저장 전에 무단으로 캡처해 가는 것을 막는 수익 보호 장치가 필요하다.
- B2B 셀러 환경에 적합한 고마진 웹 결제 구조와 검색 포털(네이버/구글)을 통한 유기적 셀러 유입 채널(SEO) 구축이 필요하다.

# Coupang AI Detail Maker 앱의 주요 기능 및 사용자 시나리오 :

- Step 0. 인증 및 크레딧 관리:
  - 구글(Google), 카카오(Kakao), 네이버(Naver) 소셜 로그인(OAuth)을 통한 간편 인증을 지원하며, 소셜 계정이 없거나 연동을 원치 않는 사용자를 위해 이메일/비밀번호 기반의 일반 회원가입 기능도 함께 제공한다.
  - 로그인한 사용자만 플랜 구독(또는 크레딧 충전) 후 에디터 워크플로우를 사용할 수 있다.
  - 작업 시작 시점이 아닌 '최종 저장 및 쿠팡 전송' 확정 시에만 크레딧(슬롯)이 1회 차감되는 원자적(Atomic) 결제/차감 정책을 운영한다.
- Step 1. 기획 단계 (경쟁사 소구점 분석 - RAG): 사용자가 참고할 쿠팡 1위 상품 URL을 입력하면, 이미지 등은 배제하고 텍스트와 리뷰 데이터만 단건/휘발성으로 크롤링한다. 가벼운 AI(테스트 단계: Gemini 1.5 Flash ➔ 상용화 단계: Claude 3.5 Haiku)가 이를 분석하여 핵심 마케팅 소구점(USP)을 체크박스 형태로 사용자에게 제안한다.
- Step 2. 폼 작성 및 1차 상세페이지 렌더링:'' 사용자는 제품명, 카테고리, 간단한 소개글, 디자인/톤앤매너 지침을 폼에 작성하고 로컬 이미지 에셋을 업로드한다. 입력된 폼 데이터, 선택된 소구점, 이미지 에셋을 메인 모델(테스트 단계: Gemini 1.5 Flash ➔ 상용화 단계: Claude 3.5 Sonnet)로 전송한다. 쿠팡 모바일 최적화 규격(780px)의 Tailwind CSS 기반 HTML 레이아웃을 즉시 렌더링한다. (Claude 전환 시 Prompt Caching 적용 고려)
- Step 3. 캡처 방지 및 하이브리드 편집:
  - 프리뷰 캔버스 최상단에는 사선 반투명 워터마크 오버레이(PREVIEW ONLY / 무단 복제 금지)를 강제 적용해 화면 캡처를 무력화한다.
  - 수동 편집(무료): 사용자는 프리뷰 화면의 텍스트를 클릭해 직접 타이핑으로 수정하고, 캔버스 내 이미지 및 디자인 요소의 위치를 마우스로 자유롭게 이동 및 크기 조절(Drag & Drop)할 수 있다.
  - AI 부분 수정(제한적): 특정 구역의 색상이나 문구 변경은 AI 채팅으로 지시할 수 있으며, 저비용 모델(Gemini ➔ Haiku) 라우팅 및 프로젝트당 최대 3회로 제한해 비용을 방어한다.
- Step 4. 최종 확인 및 쿠팡 WING 원클릭 자동 등록: 결과물에 만족한 사용자가 '워터마크 제거 및 쿠팡 등록' 버튼을 누르면 서버 DB에서 크레딧이 1회 차감되고 워터마크가 제거된 순수 HTML 코드가 반환된다. 이후 크롬 확장 프로그램(Chrome Extension)이 쿠팡 판매자 센터(WING) 상품 등록 페이지의 상세설명 에디터 입력창(DOM)에 최종 코드를 자동으로 주입한다.

# 비기능 요구사항 및 기술 스택 (Non-functional & Tech Stack) :

- 본 서비스는 Vibe 코딩 방식을 활용하여 1인 개발로 구축되며, 데스크톱 웹(Web) 환경을 타겟으로 상용화 테스트 및 배포는 Vercel 플랫폼을 이용한다.
- 프론트엔드와 백엔드(API)를 단일 레포지토리에서 처리할 수 있는 풀스택 프레임워크(Next.js)와 Tailwind CSS를 활용한다.
- Vercel AI SDK 도입 전략: 초기 개발 및 테스트 단계에서는 무료인 Gemini API를 사용하여 파이프라인 무결성을 검증하고, 상용화 시점에는 코드 변경을 최소화하여 디자인 렌더링에 탁월한 Claude API로 즉시 교체할 수 있는 유연한 어댑터 구조를 설계한다.
- 인증 및 데이터베이스: NextAuth.js(Auth.js) 또는 Supabase Auth를 활용하여 소셜 로그인(구글, 카카오, 네이버) 및 이메일 기반 일반 인증(Credentials)을 통합 구현하며, 유저 데이터 및 크레딧 관리는 Vercel과 연동하기 쉬운 서버리스 DB(Supabase 또는 Firebase)를 활용한다.
- API Key 등 민감한 정보는 Vercel의 환경변수(Environment Variables)와 Serverless API Routes를 통해 안전하게 통신한다.
- 검색엔진(구글, 네이버) 노출을 통한 자연 유입(Organic Traffic) 극대화를 위해, 에디터 대시보드(SPA)와 검색 로봇 수집용 정적 랜딩 페이지(SEO 최적화, SSR 적용)를 아키텍처상 철저히 분리 및 구성한다.
